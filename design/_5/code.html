효율적인 기부자 관리를 위한 팁

대형 기부자의 경우 메인 홀 디지털 월(Main Wall)의 가장 잘 보이는 프리미엄 위치에 자동으로 배치됩니다. 수동 조정을 원하시면 레이아웃 엔진 설정을 확인하세요.

  • verified 엑셀(CSV) 파일을 통한 대량 명단 업로드
  • verified 기부 감사장 및 영수증 자동 이메일 발송
  • verified 실시간 대시보드 통계 리포트 생성

핸동글로벌대학교는 배움과 나눔의 기회를 통해 세상을 변화시키는 기독교 창의 인재를 양성합니다.
